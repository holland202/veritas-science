The core implementation is original to this repository. Its design was informed by the author's related open research repositories, including:

- `holland202/evidence-ledger` — evidence states, contract-oriented verdicts, and integrity/authenticity distinctions.
- `holland202/veritas-eval-harness` — attestation chains, sabotage arms, and verifier anti-vacuity testing.
- `holland202/vacuity_lint.py` — static fail-path analysis and the distinction between clean and not-inspected.
- `holland202/sentinel-hai-validation` — frozen constants, preregistered gates, and run manifests.
- `holland202/eace` — fail-closed semantic verification and the principle that integrity is not truth.

These repositories are references, not runtime dependencies of the Veritas core. External adapters must record their repository and exact commit. This file does not replace the license notices of any separately distributed upstream work.
